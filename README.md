# Verilog Projects

This repository holds my Verilog FPGA projects. Each one includes the main design code and a testbench so I can inspect simulated waveforms before deploying the design onto the Basys 3 board.

## Projects

### 1. PUnC: Princeton University Computer

16-bit LC-3-style processor with a separate control unit and datapath, register file, ALU, memory, and NZP condition codes.

### 2. Simon Says Multiplayer

Four-bit Verilog Simon Says-style memory game with playback, repeat checking, and game-state LEDs.

[Read the Simon Says project README](2.%20Simon%20Says%20Multiplayer/README.md)

### 3. Switch Test

Combinational FPGA demo: 16 switches light matching LEDs only while the center button is held.

**Demo:** https://youtu.be/B0ImlxX891c
